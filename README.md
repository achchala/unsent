# unsent 💌

an iOS application for writing unsent messages, letters, and thoughts. perfect for therapeutic writing, journaling, and emotional processing.

## 🎯 project overview

**unsent** is an iOS app inspired by [the unsent project](https://theunsentproject.com/) that allows users to:
- write messages they want to express but don't actually send
- store messages privately on their device for personal reflection
- optionally share messages publicly to a community feed (anonymously)
- organize thoughts and emotions through writing
- track their emotional journey over time
- connect with others through shared human experiences
